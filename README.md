# NEO

A small code branch adding to Hugh Howey's [NEO](https://github.com/hughhowey/neo) writing app. Chaotically updated.

Features added:

* Support for series, by adding series book # on the book info page.
* User readable file names on your disk. Output is:

  series book #.chapter # {title of chapter}
  e.g. 1.01 The First Chapter.html
